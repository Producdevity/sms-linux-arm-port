Place your own Super Mario Sunshine disc image here: the USA release (game ID
GMSE01), as a single .iso, .gcm, .rvz or .wia file. Any filename works.

On muOS this folder is ports/sunshine/gamefiles at the top of the card, and with
two cards PortMaster uses the second one.

Launch the port afterwards. The first launch prepares the game on the device,
which takes a few minutes and needs about 1.1 GB of free space. The disc image
is left in place; you can delete it once the game starts.
